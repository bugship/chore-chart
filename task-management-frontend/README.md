# Chore Chart

React + Vite UI for the Chore Chart task management app.

## Scripts

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
```

Set `VITE_API_URL` to the backend API base (e.g. `http://localhost:5001/api`).

See the [root README](../README.md) for full project docs.
